# 📊 Probability and Statistics Course

This repository contains Jupyter notebooks for six computer assignments (CA1 to CA6) from the Probability and Statistics course, implemented using R. The assignments cover probability definitions, conditional probability, distributions, normal distribution, beta estimation, covariance, correlation, and sampling with simulations.

---

## 📌 Project Overview

- **CA1**: Probability definitions and the birthday problem with R simulations, including classical probability and empirical estimation of shared birthdays.
- **CA2**: Conditional probability and Monty Hall problem, exploring Bayes' theorem and win rate comparisons via simulations.
- **CA3**: Relationships between hypergeometric, binomial, and Poisson distributions, with PMF/CDF calculations and quality control simulations.
- **CA4**: Central Limit Theorem and normal distribution, demonstrating binomial-to-normal convergence with histogram overlays.
- **CA5**: Beta distribution estimation, covariance, and correlation, fitting beta to data and verifying custom statistical functions.
- **CA6**: Sampling and unbiased estimators, showing unbiasedness of sample mean/variance through simulations.
